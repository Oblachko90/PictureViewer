## ✨ About

**PictureViewer** is a fast and convenient desktop app for browsing, searching, and copying images from any folder on your PC.
Pick a folder, preview your pictures, search by name, copy with one click — and let it sit quietly in the system tray when you don't need it.

Perfect for artists, designers, meme collectors, and anyone with a chaotic `Downloads` folder. 😄

---

## 🚀 Features

| Feature | Description |
|---|---|
| 📁 **Folder picker** | Choose any folder and instantly preview all images inside. |
| 🔍 **Search by name** | Quickly filter images by filename. |
| 📋 **One-click copy** | Copy any image to the clipboard with a single button. |
| 🔀 **Sorting modes** | `A → Z`, `Z → A`, and `Random shuffle`. |
| 🗂️ **System tray** | Lives in the tray with a right-click menu. |
| 🖱️ **Tray actions** | `Show window`, `Close`, `Copy last`, `Copy random`. |
| 🌗 **Themes** | Light and Dark mode. |
| 📊 **Statistics** | Tracks images copied and app launches. |

---

## 🧭 Tray Menu

Right-click the tray icon to access:

- 🪟 **Show window** — bring the app back to front
- 📌 **Copy last** — copy the most recently copied image again
- 🎲 **Copy random** — copy a random image from the current folder
- ❌ **Close** — exit the app completely
